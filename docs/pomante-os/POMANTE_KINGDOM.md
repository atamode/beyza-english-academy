# Pomante Kingdom / Pomante Krallığı

> **Purpose:** Govern the shared story world and its relationship to Poma Academy.
> **Update trigger:** World naming, canon, setting, or product relationship changes.
> **Related files:** [Brand Guide](BRAND_GUIDE.md), [Poma Characters](POMA_CHARACTERS.md), [Vision](VISION.md)
> **Last reviewed:** 2026-07-22

## Naming

- English context: **Pomante Kingdom**.
- Turkish context: **Pomante Krallığı**.
- Forbidden variants: **Poma Kingdom**, **Poma Krallığı**.

## Role

Pomante Krallığı is the coherent character and story world used to make Poma Academy learning experiences memorable. It can connect stories, games, and lessons, but must not obscure the learning objective or confuse the umbrella/product brand relationship.

## Canon governance

Story facts, locations, character abilities, and relationships become canon only after approval and entry in this file or the linked character registry. Story-specific scripts and assets remain implementation sources; this file stores durable world rules. Current repository evidence includes Story 001; a fuller canon inventory is future research, not assumed fact.
