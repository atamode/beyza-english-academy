## Cluster rules

A hub provides navigation and synthesis. Evergreen guides answer durable questions; timely blog posts address dated developments and link back to the maintained guide. Supporting articles must not cannibalize the hub. Every item links laterally where useful and upward to the hub; commercial links appear only when contextually helpful.
