# FAQ Plan

> **Purpose:** Govern recurring questions and prevent thin, repetitive FAQ content.
> **Update trigger:** A verified question is added, consolidated, answered, or retired.
> **Related files:** [Knowledge Center](KNOWLEDGE_CENTER.md), [Schema Matrix](SCHEMA_MATRIX.md), [Article Template](ARTICLE_TEMPLATE.md)
> **Last reviewed:** 2026-07-22

## Sources

Use support questions, onboarding friction, parent/teacher feedback, Search Console queries, internal search, sales/payment questions, and usability research. Do not invent “frequently asked” questions from keyword lists alone.

## Model

- Product/account questions live near the relevant product or help surface.
- Learning questions receive a concise answer that links to the canonical evergreen guide.
- Duplicate wording is consolidated under one maintained answer.
- Each answer names an owner and review trigger when facts can change.

## Registry fields

Question; audience; evidence/source count; canonical answer URL; short answer; linked guide/product; owner; last reviewed; schema eligibility checked. FAQ structured data is optional and only used when current eligibility and visible-content rules in [Schema Matrix](SCHEMA_MATRIX.md) are satisfied.
