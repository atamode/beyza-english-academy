# Search Console

> **Purpose:** Operating record for organic search health and opportunity evidence.
> **Update trigger:** A baseline/report is reviewed, an issue appears, or a remediation is verified.
> **Related files:** [Keyword Map](KEYWORD_MAP.md), [SEO Architecture](SEO_ARCHITECTURE.md), [KPI](KPI.md)
> **Last reviewed:** 2026-07-22

## Current status

Access, property configuration, sitemap state, indexing, performance baseline, enhancements, and Core Web Vitals have not been verified in this operating record. Do not infer them from repository code.

## Baseline checklist

- Property/canonical host and user permissions.
- Sitemap submitted/read status and discovered URLs.
- Indexed, excluded, crawled-not-indexed, and duplicate/canonical patterns.
- Last 28/90 days: brand vs non-brand queries, pages, countries, devices.
- Rich-result/enhancement and structured-data issues.
- Core Web Vitals by template.
- Manual actions and security issues.

## Reporting

Record data window, comparison window, filters, exports/evidence, material movements, likely explanations labeled as hypotheses, assigned action, and verification date. Query evidence feeds [Keyword Map](KEYWORD_MAP.md); technical patterns feed [Master Tasks](MASTER_TASKS.md).
