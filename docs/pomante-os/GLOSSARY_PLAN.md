# Glossary Plan

> **Purpose:** Define a useful learning and product terminology reference.
> **Update trigger:** A verified term is added, changed, merged, or retired.
> **Related files:** [Knowledge Center](KNOWLEDGE_CENTER.md), [Editorial Guide](EDITORIAL_GUIDE.md), [Internal Linking](INTERNAL_LINKING.md)
> **Last reviewed:** 2026-07-22

## Inclusion rule

Include a term only when families, students, or educators genuinely need a plain-language explanation and the definition supports a broader learning task. Avoid dictionary-scale coverage and thin pages.

## Entry standard

Term; one-sentence definition; fuller explanation; child/parent-friendly example; common confusion; related terms; canonical guide; source/reviewer where needed; last reviewed.

Group related terms on useful hub pages unless a term supports enough distinct intent and depth for a standalone page. Definitions must be consistent with curriculum usage and link to—not copy—the canonical guide.
